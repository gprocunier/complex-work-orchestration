# Pre-Dispatch Readiness

The canonical pre-dispatch readiness contract is
[`run-readiness.md`](run-readiness.md). Read and satisfy that document in full
before broad worker handoff or operative release.

This compatibility entry point exists because released CWO instructions name
`references/pre-dispatch-readiness.md`. It does not create a second readiness
standard, relax any gate, or replace Beads as the source of truth.
