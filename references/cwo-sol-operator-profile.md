# CWO operator profile

Use the opt-in [CWO architect profile](cwo-system-prompt.md) for fresh
architect sessions. The profile sets only `model_instructions_file`.
`cwo-codex` supplies the model, reasoning effort and service tier from the
Sol role in [CWO's routing configuration](../policy/model-roles.yaml).

Follow the [installation and verification steps](cwo-system-prompt.md#install-and-verify)
and [start a fresh CWO session](cwo-system-prompt.md#start-a-fresh-cwo-session).
The [archive](cwo-system-prompt.md#history) holds the earlier operator prompts.
