# Installed plan consumer contract

Installed proposal preparation uses installed scripts, policy and schemas after
the source copy is removed. The library, JSON and command-line interfaces must
agree for equal inputs. Missing modules, policy, schema or helper inventory
refuse; proposals confer no execution or acceptance authority.

The regression suite `tests/test_installed_in_thread_plan_consumers.py` exercises
fresh installation, replacement, activation rollback and TERM rollback in
private disposable directories. It checks complete manifests, bytes and modes,
loaded module origins, per-call validator and routing observations, and unchanged
source snapshots. Each scenario retains its own state and cleanup assertions.
These are offline fixture observations, not a live first-use qualification.
