Codex Beads Hooks

Codex can show Beads SessionStart context in the shell. CWO treats that as a display problem, not a reason to reduce the context that keeps future agents oriented.

Principle Profiles Helper Subagents Validation Reference

Principle

Beads hook output is useful because it gives a new or compacted Codex session the project memory, active work, and session rules before the agent starts making decisions. The display may be noisy, but the model-visible context is still valuable.

The safe fix is display-layer suppression. Keep bd codex-hook SessionStart as the full-context path unless the installed Codex binary supports a stable visibilityHint hook field that hides presentation without changing hookSpecificOutput.additionalContext.

Do not disable hooks, redirect hook output, switch the default to memories-only context, or rely on Beads-side quiet output as a noise fix unless a validation fixture proves the model receives the same context.

Profiles

full-context Default. Uses the normal bd codex-hook lifecycle commands and accepts visible output when Codex cannot hide it safely.
quiet Adds visibilityHint: "quiet" only when support is detected or forced by an operator.
verbose Adds visibilityHint: "verbose" for inspection on supported Codex builds.
compact-degraded Requires --allow-degraded-context because it is not equivalent to full Beads context.

Helper

The helper is dry-run by default and preserves unrelated hooks. It replaces only managed Beads lifecycle hooks when --apply is passed. 

python3 scripts/configure_codex_beads_hooks.py \
  --project-dir . \
  --mode full-context \
  --json

On a Codex build with the stable display hint, quiet mode keeps the Beads commands unchanged and adds only the presentation hint: 

python3 scripts/configure_codex_beads_hooks.py \
  --project-dir . \
  --mode quiet \
  --apply

On unsupported Codex builds, quiet mode fails closed. The result includes the Codex version, inspected binary paths, and support signal so the operator can upgrade Codex or keep full-context.

Subagents

CWO still wants spawned agents and compacted sessions to recover from Beads, but support must be described accurately. Beads 1.0.5 does not support a SubagentStart Codex hook event. Until both Codex and Beads support that event, use scripts/build_beads_brief.py for internal subagent briefing and keep outside reviewers on boundary-checked contractor packets.

Validation

The acceptance check is simple: quiet display must not reduce the Beads context available to the model. Current unsupported Codex builds should show a fail-closed quiet attempt and a working full-context profile. 

SESSION_CONTEXT="$(python3 scripts/cwo.py temp path --purpose beads-hooks --name beads-sessionstart.json)"
bd codex-hook SessionStart > "$SESSION_CONTEXT"
jq -r '.hookSpecificOutput.additionalContext' "$SESSION_CONTEXT" | wc -c
python3 scripts/configure_codex_beads_hooks.py --mode quiet --json
python -m unittest tests/test_configure_codex_beads_hooks.py -v
