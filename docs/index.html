When the structure earns its keep

Use CWO when a restart, dependent change, review or handoff needs the same accepted decisions. Skip it for a short disposable task you can finish and check in one conversation.

Codex already plans, edits files, uses tools and delegates. CWO uses a system prompt optimized for complex project work rather than the default OpenAI system prompt, adding an operating contract, saved dependencies and evidence-led acceptance around those capabilities. How the pieces fit.

Status and boundaries

CWO is a development-stage public skill package. Your configured provider processes selected agent context; additional outside contractor sharing is off by default. Qualified worker execution depends on the exact tools and host. Compatibility and controls · Teaching examples.
