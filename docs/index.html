Explanation

Why the harness separates roles

Complex work fails when planning, execution, validation, and final judgment collapse into one hidden thread. This skill keeps the main Codex thread as architect, records durable state in Beads, assigns bounded work to workerbees, and treats outside or local models as evidence sources rather than implementation authority.

The result is slower than a single prompt for tiny tasks, but much safer for publication, multi-session work, contractor review, and high-risk integration decisions.
