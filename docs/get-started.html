Check your starting point

This walkthrough uses a terminal, Python 3, Git, a signed-in Codex command-line client and Beads, the task database CWO uses. Codex edits the project; CWO adds instructions for checking the work and saving a record that a later session can use. The steps below have been checked on Linux.

Already have those tools? Run this check, then go straight to installation.

Terminal

python3 --version
git --version
codex --version
bd version

All four commands should print versions. That confirms installation, not account access or a working task database. Start an ordinary authenticated Codex session before installing CWO. In step 3, bd ready --json checks task storage in the practice project. Resolve any missing command before continuing.

If a prerequisite is missing

  1. Start with your Linux terminal. Use your distribution’s package instructions for Python 3 and Git, then reopen the terminal and repeat their version checks.
  2. Set up Codex next. Follow the official Codex CLI installation and sign-in instructions. You perform account sign-in yourself; never put credentials in a project prompt. Return when codex --version works and you can start an authenticated session.
  3. Add task storage. Follow the maintained Beads installation instructions, including the backend setup required by your version. Return when bd version works. You will initialize the separate practice project in step 3.

Codex uses your model account and quota; CWO does not include model access. Your Beads version may also need a local database service. You do not need an outside-review account or a local model server for this exercise.

Already have Codex and want help checking the rest?

Prompt inside Codex

Check whether Python 3, Git, Codex CLI, and Beads are available. Explain missing prerequisites using their official instructions. Do not install packages, change global settings, authenticate for me, or bypass permissions.

Your next three stages

This walkthrough supplies a small plan so you can learn the workflow. When you bring your own project, Prompt Coach helps you shape and size its plan; the second-opinion example shows when another model can help challenge it.

  1. Install CWO and verify its CWO settings profile.
  2. Try the practice example: fix the supplied configuration checker and inspect its tests and saved work record.
  3. Continue the practice example in a fresh session to add a command you can run from the terminal.

You finish this practice example with a working configuration checker, passing tests and a handoff file explaining what was verified and what the next session should do.
