Install and verify

Install the skill, then the named profile

There are three distinct locations: the source checkout below contains the installer; the installed skill normally lives under ~/.codex/skills/complex-work-orchestration; your target project will be a separate directory. Keep them separate.

The following primary path assumes ~/cwo-source does not already exist. If it does, choose a new source folder or follow the update guide; do not delete an existing checkout.

Long commands keep their original lines. If a line continues beyond the edge, scroll inside its code block; select the text to copy it.

Terminal

git clone https://github.com/gprocunier/complex-work-orchestration.git "$HOME/cwo-source"
cd "$HOME/cwo-source"
./scripts/install.sh --yes
python3 scripts/check_installed_skill.py --check
python3 scripts/manage_instruction_profile.py install --profile operator-e
python3 scripts/manage_instruction_profile.py verify --profile operator-e

Expected: installation names its destination, the skill check reports current, and profile verification reports "ok": true. The named profile adds the operator's instructions and a launcher; it leaves default profile settings intact. The installed CWO skill remains available in ordinary sessions until disabled or removed. If a managed file is already modified, stop and inspect the reported path; do not add --force blindly. A missing bd warning is not a completed setup.

These commands use the default Codex home. If you deliberately use CODEX_HOME or CODEX_SKILLS_DIR, align the installer, check, profile, and launcher with that same home. The installation reference covers explicit destinations.
